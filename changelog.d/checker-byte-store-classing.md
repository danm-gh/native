fix: **Byte-element stores refuse float-classed values**: storing a number-array element into a `Uint8Array` element (`out[i] = codes[i]`) previously passed the checker and emitted a bit-reinterpreting narrow that diverged silently from node (116.0 stored byte 0); such a store is now the taught NS1016, naming the integer-classed idioms (integer literals, byte reads, integer math, `asciiBytes`). Cores that compiled through the silent shape must route the stored value through an integer-classed source.
- **`new Uint8Array([...])` teaches the sized form**: the initializer-list constructor previously stopped with an internal "array literal without a slice target" error; it is now the taught NS1063 — allocate sized (`new Uint8Array(4)`) and store each byte, or build text with `asciiBytes`.
