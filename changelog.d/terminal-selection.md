fix: **`<terminal>` text is selectable again**: the built-in element painted a selection wash it could never fill — the session store published every row with an empty range, so dragging across the grid did nothing. A pointer press now anchors a selection on the bound session, the drag extends it cell by cell (a press that never crosses a cell edge still selects nothing), and double- and triple-click drag by whole words and whole lines. The anchor is a tracked pin against the screen it was taken on, so output scrolling under a live drag carries it with the characters it named, and an app switching to the alt screen mid-drag invalidates it instead of selecting through to unrelated text.
- **Copy out of the terminal**: with a live selection, the platform copy chord lifts the selected text to the clipboard, trimmed. With nothing selected the same chord still reaches the child, so `Ctrl+C` remains the interrupt on hosts whose primary modifier is Ctrl.
